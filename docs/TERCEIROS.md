# Componentes de terceiros

O portfólio não carrega nada de CDNs. Estes são os componentes de terceiros distribuídos junto com ele.

| Componente | Onde | Licença | Observação |
| --- | --- | --- | --- |
| React e ReactDOM 18.3.1 | `public/vendor/react*.production.min.js` | MIT | Os arquivos mantêm o aviso de licença original no cabeçalho |
| Runtime de templates | `public/vendor/dc-runtime.js` | Não registrada | Veio do documento de referência original do portfólio; confirmar a procedência antes de reutilizá-lo em outro projeto |
| Anybody | `public/assets/fonts/` via `src/fonts.css` | SIL Open Font License 1.1 | Subconjuntos locais em WOFF2 |
| DotGothic16 | `public/assets/fonts/` via `src/fonts.css` | SIL Open Font License 1.1 | Inclui os subconjuntos japoneses |
| JetBrains Mono | `public/assets/fonts/` via `src/fonts.css` | SIL Open Font License 1.1 | Subconjuntos locais em WOFF2 |
| Simple Icons | Ícones de tecnologias no portfólio | CC0 1.0 | Creditados na tela de créditos |

A SIL Open Font License pede que o texto da licença acompanhe as fontes redistribuídas. O texto oficial está em [openfontlicense.org](https://openfontlicense.org); recomenda-se copiar o `OFL.txt` de cada família para `public/assets/fonts/`.

Marcas, personagens e jogos citados (Street Fighter, Mortal Kombat, Skullgirls, Guilty Gear, Avatar, Pokémon, Persona, Red Dead Redemption, Magic: The Gathering e outros) pertencem aos respectivos donos. O portfólio só faz homenagens com arte, textos e sons próprios; detalhes em [REFERENCIAS.md](REFERENCIAS.md).
